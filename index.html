🔒 How privacy works

No SDKs, no analytics, no ads. This app contains zero third-party tracking libraries. Location updates travel peer-to-peer via WebRTC directly between the two browsers. A lightweight public WebSocket relay is used only for the initial handshake (it never sees GPS coordinates).

iOS: Open in Safari → tap the Share icon → Add to Home Screen.
Android: Open in Chrome → tap the menu → Add to Home screen, or use the install banner above.
